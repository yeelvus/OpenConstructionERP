## 1. 目标与原则

| 原则 | 说明 |
|------|------|
| **独立模块优先** | 综合成本看板做成 OCE 标准模块（manifest + API + feature + 侧栏），不长期依赖静态 HTML |
| **快照 + 可导入** | 经营看板以月度 JSON/Excel 快照为真相源，逐步对接 finance / contracts |
| **与项目主数据关联** | 以 `project_code`（THCC-YYYY-NNN）为主键匹配 OCE 项目 |
| **定制与上游隔离** | 业务说明写在 `docs/custom/`，不写上游 `CHANGELOG.md` |
| **本地大文件不入库** | `.docker_frontend_dist/`、`.migrate/` 已 ignore |

## 3. 功能总览（按业务域）

### 3.1 综合成本看板（独立模块 `oe_thcc_cost_board`）

| 能力 | 路由 | 说明 |
|------|------|------|
| 组合层 | `/cost-board` | KPI、毛利率图、项目表筛选 |
| 项目总览 | `/cost-board/projects/:rowId` · `/projects/:id/cost-board` | 6 Tab：总览 / 预算人材机 / 采购 / 对比 / 分包 / 财务 |
| 人工专题 | `/cost-board/labor` | 项目目录 + 累计/月度构成（中方正式/劳务、属地、中介、签证） |
| 月度导入 | `/cost-board/import` | 磁盘一键 / 上传 `data_latest.json` / 上传人工 HTML |

**代码位置**

- 后端：`backend/app/modules/thcc_cost_board/`
- 前端：`frontend/src/features/thcc-cost-board/`
- 侧栏：`frontend/src/app/layout/navCatalog.ts` → Cost Control & Risk →「综合成本看板」
- API 前缀：`/api/v1/thcc-cost-board`（模块加载器自动挂载）

**数据表**

- `oe_thcc_cost_snapshot` — 月度快照 meta  
- `oe_thcc_cost_project_row` — 项目行（常用列 + `payload` JSON）  
- `oe_thcc_labor_series` — 人工月序列  

**默认数据源**

- Mac：`~/Desktop/邯郸中材/01成本统计/Z_report/综合成本看板/data_latest.json`  
- Docker：`/host/thcc/...`（compose 挂载）  
- 无编码项目：合成 `NOCODE:<名称>`  

**验证（本机 demo）**

- 导入 52 项目，其中 26 个已按 `project_code` 关联 OCE  
- 人工序列约 6348 行，period `2026-06`  

**设计长文**：[2026-08-06-综合成本看板模块化分析.md](./2026-08-06-综合成本看板模块化分析.md)

### 3.3 财务：责任成本 → 预算行

| 项 | 说明 |
|----|------|
| 源目录 | `3.1_责任成本/2_责任成本_std`（22 个项目 xlsx） |
| 实现 | `backend/app/modules/finance/thcc_resp_cost_import.py` |
| API | `/api/v1/finance/budgets/thcc-resp-cost/{config,scan,import,import-upload}/` |
| 映射 | 叶节点 `A.1`… → `wbs_id` + `category` → `oe_finance_budget` |
| 币种 | 泰铢原样；**人民币 × 4.9 → THB** |
| 联动 | 可回写成本看板 `resp_cost`（万泰铢） |
| UI | 财务 → 预算 Tab；成本看板 → 月度导入 |

**验证**：22 文件 / 22 匹配项目；全量导入成功。

### 3.4 项目主数据与列表运维

| 能力 | 说明 |
|------|------|
| 施工阶段/状态 | 生命周期 phase、中文标签、筛选 |
| 列表 | limit 默认抬到 500，避免只显示 50 条 |
| 去重归档 | `dedupe.py`：按 `project_code` / 名称合并归档 |
| 永久删除 | 仅已归档项目可硬删除 |
| 批量 | 币种、区域等批量操作 |
| 卡片/列表 | Projects 页展示增强 |
| 合同额区分 | 台账合同 vs 项目 `contract_value` vs `budget_estimate` 语义区分 |
| Excel 日期/地点 | 导入与保存不回退 |

**关键路径**：`backend/app/modules/projects/`（含 `dedupe.py`）、`frontend/src/features/projects/`
