# 定制文档目录

本目录只放 **本 fork / 本地业务** 相关记录，与上游官方文档（`docs/` 其他子目录、根目录 `CHANGELOG.md`）分开。

| 文件 | 说明 |
|------|------|
| [修改记录.md](./修改记录.md) | **主变更日志**：按日期记录每次功能/修复/运维；含续写模板 |

## 与 git 的关系

- `修改记录.md` 是给人看的中文履历，粒度可以比 commit 更细（含库内归档结果、运行环境等）。
- 仍建议重要功能单独 commit；commit 后回填 hash 到对应条目。

## 新开专题文档

需要长文设计/对比时：

```text
docs/custom/2026-08-06-项目去重说明.md
```

并在 `修改记录.md` 对应条目里用链接引用。
