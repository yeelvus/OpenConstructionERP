### 2026-08-06 · 项目去重归档 + 防重复导入 + 列表体验

| 项 | 内容 |
|----|------|
| **日期** | 2026-08-06（全天迭代，去重运维约 09:15–09:25） |
| **状态** | 工作区未提交（代码）+ 运维已执行（库内归档） |
| **版本基线** | `v14.5.0` + 既有定制提交 |
| **Commit** | —（待 commit） |
| **分支** | `feature/cn-boq-import-and-ai-tokens` |

#### 背景

- 项目多次 Excel 导入产生同编号 / 同名克隆，列表一度约 114 条，仪表盘与列表因 `limit=50` 默认只显示约 50 条，计数不一致。
- 需要按 `project_code` 与名称自动归档多余项，并避免以后再导入重复。

#### 功能与行为

1. **去重算法**（`backend/app/modules/projects/dedupe.py`）
   - 先按归一化 `project_code`（去空白、大写）分组；
   - 再对未进入「待归档」集合的**未归档**项目按归一化名称分组（同名不同编号也会合并，如「中石科技」）；
   - 保留规则：优先非归档 → 最近 `updated_at` → 最近 `created_at` → id；
   - `archive_ids` **只含尚未归档**的多余项，预览可重复执行。

2. **API**
   - `GET  /api/v1/projects/dedupe/` — 预览重复组；
   - `POST /api/v1/projects/dedupe/archive/` — 批量软删除（`status=archived`）。

3. **导入 / 创建防重**
   - Excel 导入：已有 `project_code` 或未归档同名 → `skipped_duplicate`；
   - 手动创建：已有 `project_code` → HTTP 409。

4. **列表与仪表盘**
   - 请求 `limit=500`，避免默认 50 截断；
   - 项目页：卡片/列表视图、分页大小、多字段排序；
   - 状态徽章中文标签（`active`=在建，`closing`/`settling`/`settled`/`archived` 等）。

#### 库内运维结果（本机 `~/.openestimate`）

| 指标 | 操作前（约） | 操作后 |
|------|-------------|--------|
| 总项目 | 127 | 127 |
| 未归档 | ~114（含大量克隆） | **53** |
| 已归档 | 少 | **74** |
| 未归档同 code | 多组 | **0** |
| 未归档同名 | 多组 | **0** |
| 再次预览 `would_archive` | — | **0** |

## 续写模板

复制到「## 最新」正下方：

```markdown
### YYYY-MM-DD · 一句话标题

| 项 | 内容 |
|----|------|
| **日期** | YYYY-MM-DD HH:MM +07 |
| **状态** | 已提交 / 工作区未提交 / 运维操作 |
| **版本基线** | v14.x.x |
| **Commit** | `hash` 或 — |
| **主题** | git subject 或简述 |

#### 背景

（可选）为什么要做。

#### 内容

- 要点 1
- 要点 2

#### 主要文件

- `path/to/file`

#### 运维 / 验证

（可选）接口、条数、截图说明。

#### 备注

（可选）后续 TODO、风险。
```

### 建议习惯

1. **功能做完就写一节**（不必等 commit）。
2. **commit 后**把该节状态改为「已提交」并填 hash。
3. **仅改库数据**（如批量归档）也记一节「运维操作」。
4. 大改可另建 `docs/custom/YYYY-MM-DD-专题说明.md`，本文件只留摘要并链过去。
