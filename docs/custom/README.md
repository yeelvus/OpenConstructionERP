## 与 git 的关系

- `修改记录.md` / 工作总结 是给人看的中文履历，粒度可以比 commit 更细（含库内归档结果、运行环境等）。
- 仍建议重要功能单独 commit；commit 后回填 hash 到对应条目。
- 本地构建产物与数据库 dump（`.docker_frontend_dist/`、`.migrate/`）已 ignore，勿提交。
